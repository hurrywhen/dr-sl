# DR-SL — Revised English Manuscript Mirror (Round 4, Route A)

> Concise English mirror of the revised manuscript. The authoritative full version is `latex/main.tex` / `latex/main.pdf` (18 pages). This work is a **failure-analysis and reproducible-audit study** of local release gates. **All conclusions are scoped to the audited implementation and author-constructed synthetic tests; they do not estimate failure rates of other gates or real deployments.** Earlier Markdown versions are historical process records.

## Title

Auditing Local Release Gates for Cloud-Local LLM Inference: Failure Modes of a Runtime-Sensitive-Set De-identification Chain

## Three core findings

1. **Missed extraction → false release.** Holdout-1 (shared vocabulary): 46/80 released; 36/46 (78.3%, Wilson [64.4,87.7]) retain gold literals; PASS gold L 0.147 > ALL 0.121. Banking 20/20 released with 20/20 residue ([83.9,100]); legal PASS 10/10 with residue ([72.2,100]). External FR_LLM|PASS 0.826 (19/23, [62.9,93.0]).
2. **Utility gate rewards unknown task coverage (perverse incentive).** Task-relevant recall 0.493 vs attribute recall 0.858; 37.5% harmful unmarked-context fallback (the scored context is extractor-unmarked, NOT certified non-sensitive); 30/46 releases (65%) via harmful fallback, ALL leaking (FR 1.000 vs 0.375 other releases). Coverage gate (UNSCORABLE→human): h1 releases 46→5 (57.5%→6.2%); among the 5, no false release observed (0/5, Wilson [0,0.434])—too few to validate safety; h2 release 93.8%→37.5%, FR still 1.0 (partial coverage blind). A routing policy with real cost, not a certificate; schema-level coverage is future work.
3. **No closed-loop increment.** Paired release/gold-L deltas 0[0,0] on three holdouts; local-utility delta NEGATIVE on all three (h1 −0.089[−0.117,−0.061], h2 −0.017[−0.032,−0.003], h3 −0.101[−0.130,−0.071]; fixed h3 −0.116[−0.149,−0.084]); online GEN equal leakage, higher judge utility (0.438 vs 0.362); downstream preservation paired Δ +0.025[0,0.0625] (primary judge online_alt, 2/40 disagree) / +0.025[−0.0375,0.0875] (robustness online_fast, 8/40 disagree), 23/40 identical artifacts — no detectable mean difference, not equivalence.

Confirmatory h3 (natural 50/50 mix, seed 20261122, template family #3, realized old fraction 0.389): FR 100%[92.0,100]→82.9%[68.7,91.5], recall 0.542→0.713, task recall 0.427→0.792, harmful fallback 30%→5%. Persistent false release after fixes = structural runtime-S blind spot. Contrast table reports all FR with Wilson intervals and fallback trichotomy (all/benign/harmful).
- **Neural extractor contrast (round 4, diagnostic).** Cloud-assisted qwen3.8-max, frozen prompt (declared taxonomy, verbatim values, no gold/lexicons), 200/200 calls, 0 unlocatable; same gates on h1/h3/drift-p0: recall 0.965/0.973/0.965, task recall 1.000/0.971/1.000, FR 16.1%[7.1,32.6]/16.7%[6.7,35.9]/13.3%[3.7,37.9], harmful fallback 0; paired release/leakage deltas 0, U deltas negative. Neural recall survives FULL vocabulary displacement (deterministic 0.522): the catastrophic drift failure is implementation-specific vocabulary dependence; yet 13–17% false release persists—the gate inherits even neural misses. Trust disclosure: extraction itself discloses X to the cloud → diagnostic only, not a deployable local gate. Frozen taxonomy omitted room_no/marriage_years (handled by deterministic label rules) → neural numbers are lower bounds; prompt NOT amended post hoc.
- **Vocabulary dose–response.** Holdout-2 = constructive fully-disjoint lexicon ablation (stress-condition result, NOT deployment failure rate). Drift series (h2 templates constant, overlap p∈{0,.25,.5,.75,1}, 40/level, seeds 20261123–27): realized overlap 0→1 gives recall 0.522→0.845, release 92.5%→57.5%, FR 100%→82.6% (monotonic).
