# 人工研究结果分析（修订版，2026-11-19）

输入：2 名评分员的效用评分表（sheet1.csv / sheet2.xlsx，各 160 行）+ 2 名标注员的标注复核表（各 50 行）。
复现：`python3 analyze_results.py`（输出 `analysis_results.json`）。
判定标准预注册于 `README_人工研究说明.md`；历史偏离见 `../experiment_protocol_v1.md` D15，修订偏离见 `../revision_deviations.md`。

## 研究一：语义效用人工锚点

| 指标 | 数值 |
|---|---|
| 评分员间一致性 | Krippendorff α = 0.780（序数） |
| 人工 vs 自动 U_sem 行级 Spearman ρ（n=160） | **0.839**，实例聚类 95% CI [0.774, 0.892] |
| 平均绝对误差 MAE | 0.133，实例聚类 95% CI [0.100, 0.169] |
| 操作点级 ρ（4 点） | 1.000（仅描述性，证据强度有限） |

| 操作点 | 人工均分 | 自动 U_sem | 组内 ρ | 组内 ρ 95% CI | MAE |
|---|---|---|---|---|---|
| 直接转发 | 0.988 | 1.000 | —（无方差） | — | 0.013 |
| 如实泛化 | 0.487 | 0.406 | 0.661 | [0.442, 0.830] | 0.244 |
| 占位符 | 0.144 | 0.175 | 0.784 | [0.587, 0.937] | 0.106 |
| 随机同类型替换 | 0.181 | 0.200 | 0.626 | [0.349, 0.812] | 0.169 |

阈值一致性（≥0.5）：human=1/auto=1 73；human=1/auto=0 6；human=0/auto=0 71；human=0/auto=1 10。

**修订结论：** 总体 ρ=0.839 达到预注册行级判据，但很大程度由四种操作点均值差异推动；组内相关明显更低，且实例聚类区间较宽。因此只能说明语义裁判与人工评分在总体排序上有一定一致性，不能据此证明在线放行阈值已充分校准。在线语义裁判仅用于离线效标验证，不参与本地放行。

## 研究二：标注复核

| 指标 | 数值 |
|---|---|
| 敏感项类型级精确率（标注员 1/2） | 0.959 / 0.991 |
| 敏感项类型级召回（标注员 1/2） | 1.000 / 0.987 |
| 组合风险：标注员间 κ | 1.000 |
| 组合风险：原始自动 combos 金标 κ | **−0.083（预注册判据未通过）** |
| 构念对齐金标（combos 或任一显式标识符）κ | 0.696（事后解释性分析，非预注册通过） |

**修订结论：** 人工复核支持敏感项类型覆盖，但原始组合风险标签构念未通过预注册效标。0.696 是更改构念后的事后分析，不能替代原始失败结果。以自动金标为参照计算人工召回率，也不能反向证明自动金标本身正确；后续需要独立人工标注与仲裁作为参照。
