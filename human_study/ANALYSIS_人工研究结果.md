# 人工研究结果分析（2026-09-09）

输入：2 名评分员的效用评分表（sheet1.csv / sheet2.xlsx，各 160 行）+ 2 名标注员的标注复核表（各 50 行）。
复现：`python3 analyze_results.py`（输出 `analysis_results.json`）。
判定标准预注册于 `README_人工研究说明.md`；偏离记录见 `../experiment_protocol_v1.md` D15。

## 研究一：语义效用人工锚点 —— 通过（ρ ≥ 0.8）

| 指标 | 数值 |
|---|---|
| 评分员间一致性 | Krippendorff α = 0.780（序数） |
| 人工 vs 自动 U_sem 行级 Spearman ρ（n=160） | **0.839**（判据 ≥0.8，通过） |
| 操作点级 ρ（4 点） | 1.000（排序完全一致） |

| 操作点 | 人工均分 | 自动 U_sem | 点内 ρ |
|---|---|---|---|
| 直接转发 | 0.988 | 1.000 | —（无方差） |
| **如实泛化（安全点）** | **0.487** | 0.406 | 0.661 |
| 占位符 | 0.144 | 0.175 | 0.784 |
| 选择性 LDP | 0.181 | 0.200 | 0.626 |

结论：(i) LLM 语义裁判是人工可用性判断的有效代理；(ii) 人工对诚实泛化的认可度高于语义裁判——
安全点人工效用 0.487 ≈ 精确值口径（0.033）的 15 倍，且逼近 τ_U^sem=0.5 放行阈值（即便在最坏全耦合语料上）。

## 研究二：标注复核 —— 金标覆盖验证通过；组合判定按回退条款报告

| 指标 | 数值 |
|---|---|
| 敏感项类型级精确率（标注员 1/2） | **0.959 / 0.991** |
| 敏感项类型级召回（标注员 1/2） | **1.000 / 0.987** |
| 组合风险：标注员间 κ | 1.000（完全一致） |
| 组合风险：对准标识符专用自动金标（combos）κ | −0.083（构念错位） |
| 组合风险：构念对齐金标（combos 或任一显式标识符） | 一致率 94%，**κ = 0.696** |

构念错位说明：自动 `combos` 标签仅在准标识符"定位词 × 人口属性"组合时触发；
人工题面"能否在小范围人群中唯一定位当事人"天然包含显式标识符（完整地址/电话本身即可唯一定位）。
人工 86% 判 y，自动 combos 仅 22%；对齐后自动 92% 判 y。

分歧类别分析（预注册回退条款：κ∈[0.6,0.8) → 报告并讨论）：3 处分歧全部为**纯准标识符银行实例**
（职业+收入+城市+工作年限+金额；DRSL-BNK-TST-0001/0005/0021）——规则判组合风险、两名人工均判不可唯一。
即自动标签在无显式标识符处比人工更保守（安全侧）。另注：92% 金标阳性率下 κ 受患病率效应压低（原始一致率 94%）。
