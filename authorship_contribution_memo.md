## Consistency and disclosure commitments

1. Every public record states contributions truthfully; positional wording ("second and third authors") is avoided where author order differs between versions (raters are named explicitly).
2. The order differences between versions are disclosed to the journal editor in the cover letter and declarations; the conference record carries a post-acceptance note (declarations §9).
3. The arXiv record is updated only upon acceptance (v2: conference note; v3: journal reference/DOI), per the versioning policy in the packages' declarations.
4. Supporting evidence retained: stage run logs and timestamps under `results/`, the pre-registered protocol with deviation log, git history, lab notebooks, and the human-study package.
5. No authorship role is or will be assigned as compensation, exchange, or for logistical convenience.
